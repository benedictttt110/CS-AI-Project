# B. Project Scope and Learning Goals

## B1. Target Learners

The target audience is undergraduate students who are beginning to learn Artificial Intelligence.

Learners are expected to understand basic logical reasoning and introductory programming concepts, such as variables, conditions, and lists. No previous AI course or advanced mathematical knowledge is assumed.

Technical terms will be introduced in simple language, supported by diagrams, worked examples, and practice activities.

## B2. Learning Goals

After studying the materials, learners should be able to:

1. Explain the purpose of search and problem solving in Artificial Intelligence.
2. Identify the initial state, possible actions, transition model, goal test, and path cost of a search problem.
3. Represent a simple problem using a state-space graph.
4. Describe and trace Breadth-First Search (BFS) and Depth-First Search (DFS).
5. Explain the basic purpose of Uniform-Cost Search and Greedy Best-First Search.
6. Describe how heuristic functions guide a search algorithm.
7. Explain the basic idea of A* Search and its evaluation function, f(n) = g(n) + h(n).
8. Compare search methods using simple criteria such as completeness, optimality, time, and memory.
9. Select an appropriate search method for a small problem and justify the choice.
10. Identify common errors in search traces and explain how to correct them.

## B3. Content Outline

### Topic 1: Introduction to AI Problem Solving

- Meaning and purpose of problem solving in AI.
- Search problems and state-space representation.
- Initial states, actions, transitions, and goal states.
- Path costs and simple route-finding problems.
- Representing a problem as a graph.

### Topic 2: Uninformed Search Algorithms

- Breadth-First Search (BFS).
- Queue-based exploration and level-by-level traversal.
- Depth-First Search (DFS).
- Stack-based or recursive exploration.
- Worked graph-tracing examples.
- Basic comparison of BFS and DFS.

### Topic 3: Cost-Based and Heuristic Search

- Uniform-Cost Search.
- Introduction to heuristic functions.
- Greedy Best-First Search.
- A* Search and its evaluation function.
- Step-by-step examples using graph nodes, edge costs, and heuristic estimates.
- Basic comparison of search strategies.

### Topic 4: Practice and Review

- State-space modelling exercises.
- BFS and DFS tracing exercises.
- Heuristic and A* calculation exercises.
- Search algorithm comparison questions.
- Method-selection activities.
- Common misconceptions and review questions.

## B4. Scope Boundaries

**Detailed coverage**
- Problem formulation and state-space graphs.
- BFS and DFS, including worked examples.
- Basic heuristic functions.
- A* Search using a small graph.

**Brief introduction**
- Uniform-Cost Search and Greedy Best-First Search.
- Completeness and optimality.
- Time and memory complexity at an introductory level.
- Conditions under which heuristic search is useful.

**Outside the main scope**
- Advanced proofs of search algorithm properties.
- Complex heuristic design and optimization.
- Adversarial search and game-playing algorithms.
- Constraint satisfaction problems.
- Deep learning and neural-network training.
- Advanced AI implementation techniques.

These topics are excluded to keep the project manageable for beginners.

## C5. Live Mini Lecture

**Proposed topic:** How Does A* Search Find a Promising Route?

**Importance:** A* demonstrates how an AI algorithm can combine the cost already travelled with an estimate of the cost remaining to guide its search.

**Central question:** If several possible routes are available, which node should A* explore next, and why?

**Teaching approach:**
1. Present a small graph with labelled edge costs and heuristic estimates.
2. Explain g(n), h(n), and f(n) = g(n) + h(n).
3. Ask the audience to predict which node should be explored next.
4. Calculate the evaluation values together.
5. Compare the decision with Greedy Best-First Search.
6. Summarize the main idea and ask one review question.

**Audience activity:** Learners select the next node and explain their choice to a partner or through a quick poll.

**Learning check:** Learners identify g(n), h(n), and f(n) for a given node.

The topic and duration will be checked against the teacher's approved topic menu and presentation instructions.
